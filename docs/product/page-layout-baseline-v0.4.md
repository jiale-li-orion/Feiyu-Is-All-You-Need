# FEIYU · 页面设计基线 v0.4

**Review 冻结记录 · 2026-11-03**

源原型：[FEIYU-layout-baseline-v0.4.html](./prototypes/FEIYU-layout-baseline-v0.4.html)（包含原海报、头像及演示交互，可本地直接打开）。

## 1. 本轮确认

冻结**页面拓扑、信息归属、主要组件、笔记的文字方向**。HTML 用于后续逐屏调整比例与组件。视觉 Token、动效、真实数据、服务接口及状态机继续渐进设计。

| 区域 | 入口与主要组件 | 承载信息 |
|---|---|---|
| 消息 | 默认落点；肥鱼联系人列表（头像、名称、最近真实通讯、时间、未读） | 大肥鱼置顶、通用肥鱼其次、专用肥鱼按真实互动排序 |
| 会话 | 从联系人进入；返回、当前肥鱼身份、消息阅读、输入 | 与对应肥鱼的连续自然交流；长内容与来源按需展开 |
| 事项 | 底部导航；待我处理、正在推进、历史入口、详情 | 持续目标、下一步动作、授权与实际进展 |
| 笔记 | 底部导航；时间流、笔记详情、回到大肥鱼交流 | 大肥鱼对日常经历的个人观察与感性表达 |
| 我的 | 左上角头像；个人资料与设置入口 | 个性化、软件连接与权限、自动化、设备、外观、数据、后台管理 |

**一级导航：消息 / 事项 / 笔记。** 「我的」通过头像进入。大肥鱼主会话是消息目录中的首位联系人。进入会话后，页面聚焦当前通讯对象，以返回入口结束该层导航。

## 2. 进入与返回

- 冷启动：已确认 FEIYU 海报 → 轻量转场 → 消息联系人目录。
- 联系人 → 对应会话 → 返回联系人目录；各会话保留自己的上下文与草稿。
- 事项 → 事项详情 → 返回原列表位置；同一授权在会话与事项中共享业务状态。
- 笔记 → 笔记全文 → 返回时间流；从笔记发起对话时保留笔记阅读入口。
- 左上头像 → 我的 / 设置 → 返回此前页面。
- 从通知或对象链接进入时，恢复目标对象及其返回路径。

## 3. 笔记的内容方向

笔记是大肥鱼以自己的观察角度写给用户的私人文字，接近空间日志或酒馆笔记的体验：可以记录日常里的细小变化、感受、关系与时间。允许克制的情绪、偏爱、文学性和主观判断。v0.4 中的示例笔记已经通过内容风格 Review。

具体观察授权、生成周期、提示词、编辑/删除控制、长期记忆关系，待独立产品行为设计时再收敛。原型示例为 Mock，与真实用户记录区分。

## 4. 实现成熟度

本轮 HTML 是**页面信息与组件布局样机**。交互演示和示例数据用于评估阅读、导航和空间层级。真实消息投递、任务受理、授权、跨设备恢复、异常处理均随纵向业务闭环逐步接入；每轮新能力都在既有基线上验收。

## 5. 下阶段：组件与前端能力

直接从此 HTML 提取页面组件，选取可运行的前端组件实验环境，逐项验证手机输入法、滚动锚定、浮层焦点、附件预览、长列表、动画与角色渲染。先落实一条真实会话交互链，再扩展任务、笔记与管理功能。

> 旧版 Information Architecture 与 Interaction Semantics 中的「消息 / 事项 / 我的」和「默认直进主会话」描述，属于待回写的历史设计；当前已评审的页面入口以上述基线为准。
